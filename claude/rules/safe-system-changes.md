Treat installs, migrations, and configuration changes as reversible operations. Back up anything before overwriting or removing it; never clobber unrelated user state. Run required dependency installs. If an installer has an uninstall path, verify a sandboxed install/uninstall round trip restores the original state. Distinguish versioned bootstrap files from active runtime configuration: when the user asks to change the current machine, update the active config too and verify the running tool discovers it.
